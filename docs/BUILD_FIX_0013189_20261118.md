# 00.13.189 — Correzione include-order TeamId per frontend.c

Data: 18 novembre 2026. Repository: Giuzy/SWOS-Expanded, ramo: dev/0.10. Base: 8452e1ba68ae98b1915ff71b215497c3060f2e96 (00.13.188).

## Sorgente della diagnosi
ZIP Windows: `DIAGNOSTICA_SESSIONE_1(20261118-174105).zip`.
`LEGGIMI_RISULTATI.txt` indica `BUILD_ATTESA=00.13.188` e HEAD locale identico al commit di base.
`COMPILAZIONE_0140.log` e `AVVIO_COMPILAZIONE.log`: il processo GCC compila altre unità fino a `src/frontend.c` e fallisce in fase di lettura degli header:
```text
In file included from src/frontend.c:11:
include/world_cups.h:89:35: error: unknown type name 'TeamId'
make: *** [Makefile:804: build/windows/x86_64/frontend.o] Error 1
```
Nessun altro errore GCC o warning esplicito trovato nei due log prima del fallimento. Il BAT riferisce che il gioco non è stato avviato. I file CAR nell'archivio sono copie di sicurezza: non modificarli.

## Causa
`frontend.c` include `world_cups.h` prima di `game_types.h`. L'header `world_cups.h` introdotto nella 00.13.186 pubblica `WorldCups_PreviewEntrants(const uint8_t *, TeamId *, uint16_t, int *)`, senza conoscere prima `TeamId`. Il tipo reale è la `typedef struct __attribute__((packed)) TeamId { uint8_t countryNumber; uint8_t teamOrdinal; } TeamId;` in `game_types.h`. Poiché la firma usa soltanto un puntatore, una dichiarazione anticipata del tag è sufficiente; non serve importare l'intero header di gioco.

## Correzione
- `sorgenti/include/world_cups.h`: aggiunto `typedef struct TeamId TeamId;` dopo gli include, senza modificare la definizione completa, i campi o i prototipi.
- `sorgenti/tests/test_world_cups_header_order.c`: test di regressione per entrambi gli ordini di inclusione e dimensione/firma di `TeamId`.
- `sorgenti/include/build_info.h`: versione aggiornata a `00.13.189`.

## Come verificare sulla repository locale
Con la toolchain già installata, da `sorgenti/`:
```sh
gcc -std=gnu11 -Wall -Wextra -Werror -pedantic -fsyntax-only -Iinclude tests/test_world_cups_header_order.c
gcc -std=gnu11 -Wall -Wextra -Werror -pedantic -fsyntax-only -Iinclude -DSWOS_TEST_REVERSE_TEAMID_INCLUDE=1 tests/test_world_cups_header_order.c
```
Test isolato già effettuato con GCC e Clang: forward-declaration, struct packed originale, dimensione 2 e firma con `TeamId *`, compilazione senza warning. **Non** è stato compilato il progetto completo né eseguito questo nuovo test contro tutti gli header reali della repository Windows.
