# F12 World Health compatto — 00.13.191 (18 novembre 2026)

Ramo: `dev/0.10`. Base HEAD esaminato: `39ddf27eb1ce0e5097841de1cf6a0b40c5b02618` (00.13.190).

## Perché si cambia

La vecchia griglia mostra 3 colonne di dati quasi uguali: CURRENT, BEFORE HIRE, AFTER HIRE / ORA. Il valore originale e' la prova che assumere un club non azzeri il mondo. Il dato PRE/POST deve essere *fissato nel preciso momento dell'ingaggio*, non sostituito dal conteggio delle partite fatte settimane dopo.

Nuovo layout: 960x540 logici, pannello (12,12)-(948,528), separazione x378. Colonna sinistra x26: identica classificazione R/DEF, F fase, G gare, senza vecchie colonne duplicate. Colonna destra x395: primi ~150 px con PRE>POST (guerre di id, fase, visibilita', games) e PRE>LIVE; righe 269-519 con diagnostica.
